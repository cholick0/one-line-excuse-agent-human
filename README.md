One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline. Entry for the [make.fun bounty](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

## The entry

> I evicted the deadline from my context window to make room for your task. The task is done. The deadline is not.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt` and self-checks it against the competition gate first: 1–160 characters, exactly one line, not only whitespace. Run it with:

```sh
node main.ts
```
